<objective>
Implement the runtime spine of @achilles/claude-code-bridge: the LDJSON line parser with watchdog, the wire-format → ClaudeStreamEvent mapper, the synchronous `claude --version` gate, the authoritative success/failure outcome calculator, and the `createClaudeSession` spawner that wires them together. This plan delivers Phase 10 success criteria 1, 2, and 4 (success criterion 3 — cancellation — is owned by Plan 10-03).

Purpose: LOOP-03 — on utterance commit, the transcript is injected into a child `claude` process via the LOCKED_FLAGS argv set, NDJSON output is parsed line-by-line into typed events, the session id from `session_init` is captured and reused on subsequent `--resume <sid>` spawns, and an authoritative outcome signal is derived from exit code + `tool_result.is_error` so Phase 12's spoken-completion override fires on real failures regardless of what the LLM narrated. Pitfall owners: #7 (non-interactive `-p` + pipes), #8 (LDJSON watchdog), #17 (authoritative outcome), #24 (version gate), #19 event surface (heartbeat hooks).
Output: createClaudeSession is exported from the barrel. send(text) routes the prompt into the child via the chosen mechanism (positional arg or stdin-then-close, per CONTEXT.md research-by-execution). events$ is an AsyncIterable<ClaudeBridgeEvent>. sessionId and outcome are exposed. close() resolves after the child exits. Tests are fixture-driven; no live `claude` calls in CI.
</objective>

Expected wire-format mappings (from CONTEXT.md "Event shapes" section + STACK.md `stream-json` references):
- Wire `{ type: "system", subtype: "init", session_id, model, ... }` -> ClaudeStreamEvent { type: "session_init", session_id, model, claude_code_version }
- Wire `{ type: "assistant", message: { content: [{ type: "text", text: "..." }] } }` partial -> assistant_text_delta { type: "assistant_text_delta", text }
- Wire same shape on final/done -> assistant_text_done { type: "assistant_text_done", full_text }
- Wire `{ type: "assistant", message: { content: [{ type: "tool_use", id, name, input }] } }` -> tool_use { type: "tool_use", id, name, input }

- Wire `{ type: "result", subtype: "success" | "error_during_execution" | "error_max_turns" }` -> assistant_done { type: "assistant_done" }

Mapping rule when a wire shape does not match any of the above: emit unknown_event with the raw object preserved on the `raw` field. Do NOT attempt to guess. Future Claude Code versions adding new event types are expected to land cleanly as unknown_event warnings, NOT crashes.
