<objective>
Build `@achilles/voice-stt`: the renderer-side ElevenLabs Scribe v2 Realtime client (renderer is where audio lives) plus a main-process helper that mints single-use 15-minute STT tokens against ElevenLabs `/v1/realtime/token`. The renderer-facing surface accepts ONLY a `getToken` callback — never an `apiKey`. The wrapper validates outbound hostnames via `assertElevenLabsHost` from `@achilles/voice-protocol` before opening any WebSocket. Reconnect logic implements exponential backoff with full jitter, capped at 5 attempts, distinguishing 429 rate-limit classes from network errors. A round-trip test feeds a programmatically generated 5-second 16 kHz mono Int16 PCM WAV through the wrapper against a stubbed ElevenLabs WS that returns the verbatim ground-truth transcript and asserts the emitted committed event matches.

Purpose: SAFE-01 is the explicit ownership of this plan — the ElevenLabs API key never reaches the renderer; the renderer's only credential is a 15-minute single-use token minted by the main process. LOOP-01 (mic frame -> Scribe v2 Realtime) is exercised end-to-end through the round-trip fixture but its requirement ID is assigned to Plan 09-01 (the event-contract owner) per the phase plan distribution. PITFALLS #1 (sample-rate / codec mismatch), #4 (WebSocket lifecycle + 429 distinction), #5 (locked model constant), and #22 (API key leak) are all mitigated here.

Output: A buildable, testable wrapper package that downstream phases (apps/achilles renderer in Phase 11; orchestrator in Phase 12) can consume.
</objective>
