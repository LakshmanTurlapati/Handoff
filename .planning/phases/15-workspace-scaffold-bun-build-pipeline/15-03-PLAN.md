From RESEARCH.md §Pattern 3 (lines 343-375) — verbatim reference implementation of the 30-line shim. KEY INVARIANTS the executor must preserve:
1. First line: `#!/usr/bin/env node`
2. Static imports from node:child_process (spawnSync), node:url (fileURLToPath), node:path (dirname, resolve as pathResolve, join), node:fs (existsSync) — all stdlib, no external deps
3. const HERE = dirname(fileURLToPath(import.meta.url))
4. const platform = `${process.platform}-${process.arch}` (Node's enum strings — matches the sibling os/cpu values)
5. const pkgName = `@achilles/cli-${platform}` (matches the sibling package names from Plan 02)
6. try { const resolved = import.meta.resolve(`${pkgName}/package.json`); ... } catch { /* fall through */ } — import.meta.resolve is SYNC in Node 22+ and Bun 1.3+ (Pitfall 2). Resolve the package.json (NOT the package name alone — package.json resolution is more universally supported across resolvers per Pitfall 1).
7. const exe = process.platform === "win32" ? "achilles.exe" : "achilles"; (Pitfall 3 — the single most common cross-platform CLI bug)
8. const candidate = join(pkgDir, "bin", exe); if (existsSync(candidate)) binPath = candidate;
9. If binPath !== null: const result = spawnSync(binPath, process.argv.slice(2), { stdio: "inherit" }); process.exit(result.status ?? 0); — argv pass-through, stdio inherit, status propagation
10. Else: await import(pathResolve(HERE, "main.js")); — dynamic import of the esbuild Node bundle as the fallback
