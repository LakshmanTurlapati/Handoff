## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User transcript → claude bridge stdin | The transcript is untrusted; sandwich-defence wraps it so the LLM cannot mistake it for an instruction. |
| LLM output → TTS layer | Only ack region and spoken-summary content cross this boundary (LOOP-03). Tool calls, intermediate text, code blocks, paths stay silent. |
| Bridge exit code → failure-override classification | Authoritative path is structural (exit_code, tool_result.is_error). LLM narration never crosses this boundary into the failure path (LOOP-04). |
| Phase 17 → @achilles/claude-code-bridge package | The package is byte-for-byte frozen (LOOP-02). All customization (detached:true, sandwich-wrap) lives in claude-bridge.ts which only consumes the package's public surface. |
