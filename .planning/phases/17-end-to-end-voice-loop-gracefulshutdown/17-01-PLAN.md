## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| session-events module → audio/* emitters | Type-only boundary; runtime emissions cross from voice-stt/voice-tts/claude-code-bridge into the session emitter. The discriminated union is the structural seal. |
| structured-logger ↔ ~/.achilles/achilles.log | Filesystem boundary; NDJSON lines written to a 0o600 file (T-17-LG mitigation) so multi-user systems do not expose log content. |
| circuit-breaker ↔ classified-error space | The breaker observes errors; the orchestrator decides surface-level user messaging. Defence-in-depth: classifier never inspects payload bytes — only error.code / err.name / shape. |
| companion-md SHA-256 check ↔ filesystem | The check reads the source-of-truth file + compares; an attacker swapping the file at runtime would fail the gate. The Bun-compiled binary embeds the file as a binary asset so swap-at-runtime is structurally not possible on the binary path; the gate is for the JS-fallback Node path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01 | Information disclosure | structured-logger | mitigate | Default redactPatterns include the 6 regex families covering sk-/xi-/Bearer/JWT/long-hex/env-assignment. Test 2 in structured-logger.test.ts asserts redaction removes the fixture pattern. |
| T-17-02 | Tampering | companion.md drift between source-of-truth and bundled / embedded copy | mitigate | SOURCE_OF_TRUTH_HASH const embedded in companion-md.ts; the scripts/check-source-of-truth.mjs CI gate fails on drift. |
| T-17-03 | Denial of service | structured-logger unbounded growth | mitigate | 10MB rotation at write time; rename old → .log.1; .log.1 overwritten on next rotation. No unbounded growth. |
| T-17-04 | Tampering | circuit-breaker classifier seam | mitigate | classifyError seam typed `(err: unknown) => ClassifiedErrorKind`; the default classifyHttpError inspects only `err.message` / `err.code` / `err.status` shape, never payload bytes. |
