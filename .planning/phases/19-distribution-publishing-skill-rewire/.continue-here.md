## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Cut-before-publish | Deleting `apps/achilles` + `apps/achilles-cli/src/commands/launch.ts` before `npm publish` completes successfully would orphan the workspace on a publish failure (no recoverable artifact for rollback) | blocking | D-08/D-09 publish-then-cut ordering enforced in Plan 19-04: single cleanup commit AFTER publish-success; operator runs 5 `npm view` assertions BEFORE Plan 19-04's deletion commit B lands |
| Parent-before-siblings publish | Publishing parent `achilles@1.3.0` before the 3 sibling packages creates a window where `npm install -g achilles` hits missing `optionalDependencies` (warnings, ugly UX) | blocking | achilles-release.yml jobs run sequentially: build -> publish-siblings -> publish-skill -> publish-parent -> macos-smoke (RESEARCH Pattern 2) |
| Auto-running release workflow | Triggering `npm publish` from Claude Code violates CLAUDE.md never-auto-run rule and ships an unreviewed release | blocking | achilles-release.yml has `on: workflow_dispatch` ONLY (no `push` trigger); operator manually triggers via GitHub Actions UI |
| LOOP-02 invariant break | Any byte-level change to `packages/voice-*`, `claude-code-bridge/`, or `packages/achilles-skill/skill/prompts/companion.md` breaks the v1.2 trust contract | blocking | SHA-256 source-of-truth check (Plan 19-03) verifies companion.md byte-for-byte equality between source and in-tarball copy; runs as `prepublishOnly` hook |
| INIT-07 invariant break | Adding static imports to `apps/achilles-terminal/src/cli.ts` top-level beyond `{node:fs/promises, node:url, node:path}` breaks the --version-without-pipeline-boot guarantee | advisory | Plan 19-02 added the 6th dynamic-import gate (install-skill) inside `main()`; integration test at `tests/integration/init-07-invariant.test.ts` enforces the budget |
