<objective>
Implement SAFE-06 resilience — three independent modules wired through session.ts and the renderer mic-capture:

  1. stuck-thinking-watchdog: 60-second timer that fires when Claude emits no progress events; orchestrator audibly announces the stall and the user can cancel via the existing hotkey path.
  2. suspend-resume-handler: Electron powerMonitor 'suspend' / 'resume' (plus 'lock-screen' / 'unlock-screen') listeners; on suspend pause mic + close bridge + stop TTS; on resume return to idle.
  3. device-change-handler: navigator.mediaDevices.ondevicechange observer (renderer); on change tear down + re-acquire mic stream; Bluetooth-HFP downgrade emits a warning log but continues.

All three modules use injected seams (setTimeoutImpl, powerMonitorRef, navigatorRef) so tests run without any real Electron / OS / audio device. Plan 14-04 depends on Plans 14-01/14-02/14-03 because session.ts has accumulated several deps additions; the merge here happens cleanly because 14-04's additions are different fields and the wiring point (consumeClaudeEvents progress observation) is non-overlapping with 14-03's circuit wiring.

Purpose: SAFE-06 turns three failure modes (hung Claude, OS suspend, device change) from "Achilles is broken" into "Achilles recovers." Each is independently testable.
