<objective>
Implement graceful degradation (SAFE-05) — STT failure surfaces a typed-prompt fallback in the UI; TTS failure surfaces completion text visibly in the UI and prints it to the launching terminal; ElevenLabs incident detection wraps both clients with circuit-breaker plus exponential-backoff-with-full-jitter retry semantics.

The incident-detection module is a pure circuit breaker — error classification plus backoff math plus state tracking — that the orchestrator wraps around its STT token-mint AND its TTS open() attempt. When the circuit opens, the orchestrator stops retrying and broadcasts the failure to the renderer.

The TypedFallback component is the UX critical path: a user whose STT is failing must be able to continue talking to Claude by typing instead. The typed text flows through the SAME orchestrator path as a spoken commit (sandwich-defence wrap plus claude bridge send plus TTS playback) so no separate code path exists.

The IncidentStatus dot reflects current STT + TTS health in the corner of the floating window.

Purpose: SAFE-05 turns ElevenLabs-down from "Achilles stops working" into "Achilles tells the user how to continue."
