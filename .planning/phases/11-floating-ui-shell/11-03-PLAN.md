<objective>
Implement the three remaining Phase 11 surfaces: (1) drag-to-reposition with persistence (UI-05) — `electron-store`-backed window-position writes on every move, with the persisted position honoured on relaunch; (2) the macOS mic permission flow (UI-07) — `systemPreferences.askForMediaAccess('microphone')` owned by the Electron host, three permission states ('not-determined' deferred, 'denied' / 'restricted' surfaced via `<PermissionOverlay>`), and the deep-link to `x-apple.systempreferences:com.apple.preference.security?Privacy_Microphone`; (3) the supporting UI surfaces — `<SettingsPopover>` (hotkey mode toggle, hotkey capture, reset window position), `<ErrorBanner>` (260×90 banner for the four mocked error kinds with auto-dismiss + Dismiss button), and `<DragHandle>` (the invisible 260×30 `-webkit-app-region: drag` region). Compose everything together in a new `App.tsx` that supplies the three overlay slots to the FloatingShell from Plan 11-02.

Purpose: These three concerns (drag persistence, permission, settings + error) are independent of the visual state surface (UI-02/03/04 + LOOP-02 from Plan 11-02) and naturally bundle here because they share the same architectural shape — main owns the OS-level concern (move events, permission probe, settings persistence), the renderer renders the affordance, the bridge schemas in Plan 11-01 already cover the IPC. Plan 11-03 closes Phase 11's renderer-side surfaces; the result is an Achilles UI that a fresh-account macOS reviewer can drive end-to-end against the mocked state machine (UI-01 + UI-02 + UI-03 + UI-04 + UI-05 + UI-06 + UI-07 + LOOP-02 — all 8 phase requirements covered after this plan ships).

Output: A fully functional Achilles renderer covering UI-05 + UI-07 against the Plan 11-01 mock bridge, the three remaining UI-SPEC components (PermissionOverlay, SettingsPopover, ErrorBanner) + DragHandle, the main-process wiring for drag persistence and permission flow, and four Playwright headless specs proving drag persistence, permission overlay, settings popover, and error banner.
</objective>
