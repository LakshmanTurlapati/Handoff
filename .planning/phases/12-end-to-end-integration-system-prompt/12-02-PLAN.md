<objective>
Plan 12-02 ships the two security wrapper modules that sit between the renderer-side STT commit and the Claude bridge / TTS layers: `sandwich-defence.ts` (SAFE-04 — wraps the transcript as untrusted user input between explicit delimiters before passing it to `claude -p`) and `normalisation.ts` (pre-TTS string normalisation — strips ANSI, paths, secrets, fenced code, hard-caps to 600 chars).

Purpose: SAFE-04 mandates that instruction-shaped content inside a transcript MUST NOT override the embedded contract from companion.md. The sandwich-defence wrapper is the structural guarantee that the delimiters cleanly separate trusted system prompt from untrusted user voice. Pre-TTS normalisation (PITFALLS #16 + #21) is the belt-and-braces guard against the model occasionally emitting paths, ANSI escapes, or secret-shaped strings inside the spoken-summary block. Both modules are pure functions and have NO dependency on Electron, IPC, or the voice loop — they are composable string transforms.

Output: Two production modules with exhaustive unit-test coverage and a separate adversarial-fixture generator that produces manipulation patterns via deterministic transforms (per the CONTEXT.md adversarial-fixture rule and the quality gate, no verbatim injection-trigger strings appear in committed test source).

Phase boundary: Plan 12-02 does NOT compose these helpers into the orchestrator (Plan 12-04 owns session.ts). It does NOT wire IPC. It does NOT touch ElevenLabs. The output is two pure string transforms plus their tests; downstream plans (12-03 renderer, 12-04 orchestrator) consume them.
