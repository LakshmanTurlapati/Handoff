<objective>
Deliver the `achilles init` first-run wizard (DIST-04) — a three-step flow that collects the ElevenLabs API key, requests microphone permission via the Electron host (not the launching terminal — Pitfall #3 mitigation), and runs an end-to-end smoke round-trip ("say something — hear something back") before exiting cleanly.

The CLI side (`achilles init`) launches the Electron app with `ACHILLES_MODE=init` in the env. The main process routes on this env var to create the InitWizard child BrowserWindow (reusing Plan 11-03's settings-popover-window pattern verbatim — same window-config primitive, frameless, focusable, centred). The renderer mounts the InitWizard.tsx component (a three-step state machine: ApiKey → MicPermission → SmokeRoundTrip → Done). On Step 1 the key is persisted via Plan 12-04's `AchillesStore.writeElevenlabsApiKey` (safeStorage-backed). On Step 2 the main process invokes `systemPreferences.askForMediaAccess('microphone')` via the Plan 11-03 `probePermission` helper. On Step 3 the main process drives a one-shot real ElevenLabs / Claude round-trip OR — when offline / MOCK_LOOP=1 — uses the deterministic mock-loop-clients from Plan 12-04.

The smoke round-trip's PROMPT-LEVEL contract: Claude is asked a fixed canned question with a small fixed system prompt that mandates the canned reply "Hello from Achilles, I am ready to help." — the user hears that playback and the wizard knows it's done. The wizard is forgiving on Step 3 timeout (60s budget): if the round-trip stalls, the user sees a "skip smoke test" button that exits the wizard non-fatally.

Purpose: Closes DIST-04 — without an init wizard, a fresh-install user has no way to enter their ElevenLabs key without diving into the OS keystore. This is the first-run UX gate. Pitfall #3 mitigation is structural: the wizard's mic prompt comes from the Electron host, not from the launching terminal.

Output: A user freshly installed via `npm install -g achilles` runs `achilles init` and within 60 seconds has a working voice loop (key stored, mic granted, audible TTS confirmation). The wizard exits 0 on success; the CLI process exits 0; the user can now run `achilles` (no args) to launch the regular floating UI.
</objective>
