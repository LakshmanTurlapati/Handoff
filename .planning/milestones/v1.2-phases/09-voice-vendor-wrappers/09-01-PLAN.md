<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer (BrowserWindow) -> Main (Electron main) | Renderer asks for STT token via IPC; main mints and returns. Raw ElevenLabs API key must never traverse this boundary. |
| Wrapper packages -> ElevenLabs cloud | All outbound traffic is over WSS / HTTPS to api.elevenlabs.io and its regional siblings. Any other host is a policy violation. |
| Downstream consumers (apps/achilles main + renderer, Phase 11) -> voice-protocol | Consumers will rely on Zod schemas to validate IPC payloads at runtime; weak schemas equate to weak boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Information Disclosure | MintSttTokenRequestSchema (ipc.ts) | mitigate | `.strict()` Zod modifier refuses unknown keys so a renderer cannot piggyback an `apiKey` field into the IPC envelope (SAFE-01). |
| T-09-02 | Information Disclosure | MintSttTokenResponseSchema (ipc.ts) | mitigate | `refine()` rejects token values whose shape matches ELEVENLABS_KEY_PREFIX + length floor (defence in depth against a main-process bug that would return the raw key instead of a single-use token). |
| T-09-03 | Tampering | transport.ts allowlist matcher | mitigate | Suffix check uses label-boundary parsing (split on dots, compare trailing labels) to refuse "api.elevenlabs.io.evil.com" and other substring-attack hostnames. Unit tests assert the rejection. |
| T-09-04 | Spoofing | TtsChunkSchema sequence field | mitigate | Sequence is constrained to a non-negative integer; downstream ordering tests (Plan 09-03) rely on this for monotonicity. Without the schema constraint, a malformed chunk could spoof its position. |
| T-09-05 | Denial of Service | SttEventSchema discriminated union | accept | Zod parse failures throw at the wrapper boundary; downstream callers must handle. Acceptable for v1.2 because the failure surface is local and observable. |
| T-09-SC | Tampering | npm install zod 4.3.6 | mitigate | zod is already in the monorepo at version 4.3.6 (packages/protocol/package.json). No new package install in this plan; install legitimacy is inherited from the existing audit. Confirm no new package-manager add is performed. |
</threat_model>
