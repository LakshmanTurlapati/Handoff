## Overview

Achilles is a voice companion for Claude Code. It installs as both a Claude Code skill and an npm global CLI from a single source of truth, opens a small reactive floating UI (260x260 px Electron panel) with a state-driven circle and waveform, captures microphone input, transcribes via ElevenLabs Scribe v2 Realtime, pipes the transcript into a local `claude -p --output-format stream-json` subprocess, extracts a tight spoken acknowledgement and `<spoken-summary>` block, and speaks them back via ElevenLabs Flash v2.5. The companion system prompt, distribution surfaces, security boundaries, half-duplex turn-taking, and resilience layers were all delivered together in this milestone.

This milestone was a pivot from v1.1 (Handoff Install & Launch), which is paused at Phase 08.1 and preserved for resumption. v1.2 lives alongside the existing Handoff codebase (`apps/web`, `apps/relay`, `apps/bridge`) without touching it.

**Key Decisions (locked at milestone scoping, honoured throughout):**
- **Local Claude Code only.** Cloud-hosted Claude Code routing deferred to v1.3 (CLOUD-01) because skills/STT/floating-UI cannot reach the developer's mic over the cloud sandbox boundary. v1.2 distribution surfaces (npm, Claude Code skill install) remain "cloud-installed; locally executed".
- **Both press-to-toggle AND push-to-talk hotkey modes, switchable in settings.** Honours both ChatGPT-style PTT and Claude Code `/voice` precedent.
- **One fixed default ElevenLabs voice with env var override.** No picker UI in v1.2.
- **Subprocess `claude -p --output-format stream-json` is the Claude bridge spine** (not Agent SDK). Universal, version-independent, sidesteps Ink stdin/Enter gotcha (anthropics/claude-code#15553).
- **One artifact, two install surfaces.** `npm install -g achilles` plus `achilles install-skill` symlink yields both the CLI and the skill from one source of truth, gated by a SHA-256 diff check on `companion.md`.
- **Half-duplex turn-taking.** Mic gated during TTS playback (300 ms debounce after last chunk drains). Full-duplex AEC is explicit v2+ work.
- **Authoritative outcome from exit code + tool_result events, never LLM narration.** PROMPT-05 override "I ran into a problem" derived structurally.
